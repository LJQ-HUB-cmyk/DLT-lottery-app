# 📊 Google Analytics 集成指南

本文档说明如何配置和使用数据统计功能。

---

## 🎯 功能概述

集成 Google Analytics 4 后，您可以追踪以下数据：

### **用户指标**
- 👥 活跃用户数（日活、月活）
- 🌍 用户地理位置
- 📱 设备类型（手机/平板/电脑）
- 🌐 浏览器类型
- ⏱️ 平均访问时长

### **行为指标**
- 📄 页面浏览量
- 🖱️ 号码生成次数
- 📋 复制操作次数
- 💾 保存文件次数
- 🔄 数据更新次数

### **模型使用情况**
- 📈 各模型使用频率
- 🎲 每次生成的组数
- ⚙️ 模型组合偏好

## 🚀 配置步骤

### 第一步：创建 Google Analytics 账号

1. **访问 Google Analytics**
   - 打开 https://analytics.google.com
   - 点击"开始衡量"

2. **创建账号**
   - 输入账号名称（例如：发财大计）
   - 接受数据共享设置

3. **创建媒体资源**
   - 资源名称：lottery-app
   - 报告时区：中国标准时间
   - 货币：人民币 (CNY)

4. **获取测量 ID**
   - 完成设置后，您会看到一个以 `G-` 开头的 ID
   - 格式类似：`G-XXXXXXXXXX`
   - 复制这个 ID

### 第二步：配置项目

1. **创建环境变量文件**
   ```bash
   cd d:\0.Code\0.发财大计\lottery-app
   copy .env.example .env
   ```

2. **编辑 .env 文件**
   ```env
   # 将 G-XXXXXXXXXX 替换为您的实际测量 ID
   VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX
   ```

3. **重新编译项目**
   ```bash
   npm run build
   ```

### 第三步：验证配置

1. **打开实时报告**
   - 在 Google Analytics 中，左侧菜单选择"报告" → "实时"
   
2. **访问您的网站**
   - 打开部署后的网站
   - 应该能在实时报告中看到自己的访问

3. **测试事件追踪**
   - 点击"一键生成号码"
   - 点击"一键复制"
   - 在 GA 后台查看事件是否记录

## 📈 查看数据

### **实时数据**
- 路径：报告 → 实时
- 显示当前在线用户数和最近30分钟的活动

### **用户数据**
- 路径：报告 → 用户 → 用户属性
- 查看用户数量、地理位置、设备等

### **事件数据**
- 路径：报告 → 互动 → 事件
- 查看所有追踪的事件：
  - `generate_numbers`：号码生成
  - `copy_results`：复制操作
  - `save_results`：保存操作
  - `update_data`：数据更新
  - `select_models`：模型选择

### **自定义报告**

#### 1. 最受欢迎的模型
```
维度：event_label (模型名称)
指标：event count (事件次数)
```

#### 2. 平均每组生成数量
```
维度：model_name
指标：value (平均值)
```

#### 3. 用户转化漏斗
```
1. page_view (访问页面)
2. generate_numbers (生成号码)
3. copy_results / save_results (复制/保存)
```

## 🔍 追踪的事件详情

### 1. 号码生成 (generate_numbers)
```javascript
trackNumberGeneration(model, groups)
```
**参数：**
- `model`: 使用的模型名称
- `groups`: 生成的组数

**用途：** 了解哪个模型最受欢迎，用户通常生成多少组

### 2. 复制结果 (copy_results)
```javascript
trackCopy()
```
**用途：** 统计有多少用户复制了预测结果

### 3. 保存文件 (save_results)
```javascript
trackSave()
```
**用途：** 统计有多少用户保存了预测结果

### 4. 数据更新 (update_data)
```javascript
trackDataUpdate(dataCount)
```
**参数：**
- `dataCount`: 加载的历史数据条数

**用途：** 了解用户使用自定义数据的情况

### 5. 模型选择 (select_models)
```javascript
trackModelSelection(models)
```
**参数：**
- `models`: 选中的模型列表

**用途：** 了解用户喜欢使用哪些模型组合

## 🛡️ 隐私保护

### GDPR 合规建议

如果您有欧盟用户，建议添加 Cookie 同意弹窗：

1. **安装 Cookie 同意插件**
   ```bash
   npm install react-cookie-consent
   ```

2. **在 App.jsx 中添加**
   ```jsx
   import CookieConsent from 'react-cookie-consent';
   
   // 在 return 的最外层添加
   <CookieConsent
     location="bottom"
     buttonText="同意"
     declineButtonText="拒绝"
     enableDeclineButton
     onAccept={() => {
       // 用户同意后初始化 GA
       initGA();
     }}
   >
     我们使用 Cookie 来分析网站使用情况
   </CookieConsent>
   ```

Google Analytics 默认会匿名化 IP 地址，无需额外配置。

## 📊 数据分析示例

### 问题 1：哪个模型最受欢迎？

**查询方法：**
1. 进入"报告" → "互动" → "事件"
2. 找到 `generate_numbers` 事件
3. 按 `event_label` 分组查看

**优化建议：**
- 如果某个模型使用率很低，考虑优化或移除
- 如果某个模型特别受欢迎，可以重点优化

### 问题 2：用户转化率如何？

**计算方法：**
```
转化率 = (复制次数 + 保存次数) / 生成次数 × 100%
```

**优化建议：**
- 如果转化率低，可能需要改进用户体验
- 检查生成的号码质量是否满足用户需求

### 问题 3：用户使用习惯是什么？

**分析维度：**
- 平均每次生成多少组？
- 喜欢单选还是多选模型？
- 什么时间段用户最多？
- 移动端和桌面端的使用差异？

## ❓ 常见问题

### Q: 数据多久更新一次？
A: 实时数据几乎即时更新，完整报告需要 24-48 小时处理。

### Q: 可以过滤自己的访问吗？
A: 可以！在 GA 设置中创建过滤器，排除您的 IP 地址。

### Q: 数据会保留多久？
A: 默认保留 14 个月，可以在设置中调整为 2 个月、14 个月、26 个月、38 个月或 50 个月。

### Q: 免费版的限制是什么？
A: 
- 每月 1000 万次事件
- 50 个自定义维度
- 对于个人项目完全够用

### Q: 如何导出数据？
A: 在报告中点击右上角的"导出"按钮，支持 CSV、Excel、PDF 等格式。
