## 📝 配置步骤（5分钟完成）

### 第一步：注册百度统计账号（2分钟）

1. **访问百度统计**
   ```
   https://tongji.baidu.com
   ```

2. **登录/注册**
   - 使用百度账号登录
   - 如果没有百度账号，先注册一个

3. **新增网站**
   - 登录后点击"新增网站"
   - 填写信息：
     - **网站域名**：您的部署域名（例如：`yourname.github.io`）
     - **网站名称**：发财大计
     - **网站主页**：`https://yourname.github.io/lottery-app/`
   - 点击"确定"

4. **获取站点 ID**
   - 添加成功后，您会看到一段代码
   - 找到类似这样的数字：`hm.js?12345678901234567890`
   - 这串数字就是您的**站点 ID**
   - 复制它（纯数字，不要包含其他内容）

### 第二步：配置项目（1分钟）

在 `lottery-app` 目录下创建 `.env` 文件：

```bash
cd d:\0.Code\0.发财大计\lottery-app
```

创建文件 `.env`，内容如下：

```env
VITE_BAIDU_TONGJI_ID=您的站点ID
```

**示例：**
```env
VITE_BAIDU_TONGJI_ID=12345678901234567890
```

⚠️ **注意**：只填数字，不要引号，不要空格

### 第三步：重新编译（1分钟）

```bash
npm run build
```

### 第四步：部署并验证（1分钟）

1. **部署到 GitHub Pages / Vercel / Cloudflare**

2. **访问您的网站**
   - 打开部署后的网址
   - 正常使用应用

3. **查看实时数据**
   - 回到百度统计后台
   - 点击左侧菜单"实时访客"
   - 应该能看到自己的访问记录
   - 显示"当前在线：1人"就说明配置成功！

## 🎯 关键指标解读

### 如何知道有多少用户在用？

**查看位置**：报告 → 基础报告 → 趋势分析

**关键指标**：
- **PV（页面浏览量）**：总访问次数
- **UV（独立访客）**：有多少不同的用户
- **IP 数**：有多少不同的 IP 地址

**建议关注**：UV（独立访客数），这代表真实用户数量

### 如何知道生成了多少次数据？

**查看位置**：报告 → 事件分析

**筛选条件**：
- 事件分类：`prediction`
- 事件动作：`generate_numbers`

**可以看到**：
- 总生成次数
- 按模型分类的生成次数
- 每次生成的组数

### 如何知道哪个模型最受欢迎？

**查看位置**：报告 → 事件分析

**操作**：
1. 选择事件：`generate_numbers`
2. 按"事件标签"分组
3. 查看各模型的触发次数

**结果示例**：
```
rotation    - 150 次
zhouyi      - 120 次
statistical - 80 次
bayesian    - 50 次
```

这说明旋转矩阵模型最受欢迎！

### 如何计算用户转化率？

**公式**：
```
转化率 = (复制次数 + 保存次数) / 生成次数 × 100%
```

**查看方法**：
1. 生成次数：事件 `generate_numbers` 的总数
2. 复制次数：事件 `copy_results` 的总数
3. 保存次数：事件 `save_results` 的总数

**示例**：
- 生成 1000 次
- 复制 300 次
- 保存 100 次
- 转化率 = (300 + 100) / 1000 = 40%

## 💡 高级技巧

### 1. 设置目标转化

在百度统计中可以设置转化目标：

1. 进入"管理" → "转化目标"
2. 添加新目标：
   - 目标名称：生成号码
   - 目标类型：事件
   - 事件分类：`prediction`
   - 事件动作：`generate_numbers`

3. 可以设置多个目标：
   - 生成号码
   - 复制结果
   - 保存文件

### 2. 自定义报表

创建个性化的数据看板：

1. 进入"管理" → "自定义报表"
2. 添加关注的指标：
   - 访问量趋势
   - 事件统计
   - 用户画像

3. 保存到首页，每天打开就能看到关键数据

### 3. 数据导出

需要详细分析时可以导出数据：

1. 在任何报告页面点击右上角"导出"
2. 支持格式：Excel、CSV、PDF
3. 可以导出指定时间段的数据

### 4. 对比分析

比较不同时间段的表现：

1. 在报告页面选择时间范围
2. 点击"对比"按钮
3. 选择对比的时间段
4. 查看增长/下降趋势

## 🔧 常见问题

### Q: 看不到实时数据怎么办？

A: 
1. 检查站点 ID 是否正确（纯数字）
2. 确认 `.env` 文件已创建且配置正确
3. 确认已重新编译并部署
4. 清除浏览器缓存后重试
5. 等待 1-2 分钟再查看

### Q: 数据多久更新一次？

A:
- **实时数据**：几乎即时（延迟 1-2 分钟）
- **基础报告**：每小时更新
- **完整报告**：第二天早上更新前一天的数据

### Q: 可以过滤自己的访问吗？

A: 可以！
1. 进入"管理" → "IP 排除"
2. 添加您的 IP 地址
3. 这样您的访问就不会被统计

**查看自己的 IP**：访问 https://ip.cn

### Q: 免费版有限制吗？

A: 
- ✅ 无流量限制
- ✅ 无数据存储限制
- ✅ 功能完整
- 对于个人项目完全够用

### Q: 数据会保留多久？

A: 
- 默认保留最近 2 年的数据
- 可以在设置中调整

### Q: 如何绑定多个域名？

A: 
1. 在百度统计后台点击"新增网站"
2. 添加新的域名
3. 每个域名会有独立的站点 ID
4. 在不同环境中使用不同的 ID
