# 区间频率分析算法 v2 - 多因子综合评分模型

## 🎯 核心设计理念

**目标**：实现一个高命中率的预测算法，不是简单的"哪个号码出现次数多就选哪个"，而是综合考虑多个维度的因素。

## 📊 算法架构

### 三层评分体系

#### 第一层：区间定位（30%权重）
```
前区分7个区：
区1: 01-05  区2: 06-10  区3: 11-15  区4: 16-20
区5: 21-25  区6: 26-30  区7: 31-35

后区分2个区：
区1: 01-06  区2: 07-12
```

- 计算每个区间的综合评分
- 选择最热的4个前区区间、2个后区区间
- 确保覆盖面，避免号码集中在某个区域

#### 第二层：号码多因子综合评分（70%权重）

对每个号码进行6个维度的评分：

**1. 频率分（25%）**
- 基于历史出现次数
- 出现次数越多，分数越高
- 但做了归一化处理，避免某些号码分数过高

**2. 遗漏回归分（25%）** ⭐核心创新
- 计算当前遗漏值 vs 平均遗漏值
- 偏离越大，回归倾向越强
- 例如：某号码平均10期出一次，现在已遗漏30期 → 回归倾向极强
- 但超过2倍标准差会适度降低，避免选择极端冷号

**3. 趋势分（20%）** 核心创新
- 对比近10期频率 vs 近30期期望频率
- trendRatio = 近10期实际频率 / 近30期推算的期望频率
- trendRatio > 1 → 上升趋势（热号可能继续热）
- trendRatio < 1 → 下降趋势（热号可能转冷）
- 适度偏好上升趋势，但避免过热

**4. 关联分（15%）**
- 基于号码共现频率
- 某些号码经常一起出现（如03和09）
- 如果选中的其他号码与某个号码关联度高，加分

**5. 和值适配分（10%）**
- 历史开奖的和值有规律（前区和值通常在60-100之间）
- 评估该号码加入后，整体和值是否符合历史分布

**6. 位置偏好分（5%）**
- 某些号码喜欢在特定位置出现（如03经常在第2位）
- 暂时给基础分，后续可以细化

#### 第三层：动态调整机制

**回补效应**
- 如果某区间连续3期未出 → 提升该区间权重
- 长期未出的区间有回补需求

**防过热机制**
- 如果某号码近5期连续出现 → 降低其权重
- 避免选择过热的号码

## 🔬 算法示例

假设历史数据统计后：

### 区3（11-15）的综合评分计算

**号码13：**
- 频率分：出现18次 → 20分
- 遗漏回归分：平均遗漏12期，当前遗漏28期 → 偏离1.33倍 → 25分
- 趋势分：近10期出现2次，近30期出现4次 → trendRatio=1.5（上升） → 15分
- 关联分：与09、23共现频率高 → 12分
- 和值适配分：9分
- 位置偏好分：5分
- **总分：86分** ⭐

**号码14：**
- 频率分：15次 → 16分
- 遗漏回归分：当前遗漏5期 → 偏离小 → 10分
- 趋势分：trendRatio=0.8（下降） → 11分
- 关联分：8分
- 和值适配分：9分
- 位置偏好分：5分
- **总分：59分**

**结果**：选择13而不是14，因为13的综合评分更高（遗漏回归+上升趋势）

### 最终选号逻辑

1. 计算所有7个区间的综合评分
2. 选择最热的4个区间（假设是区2、区3、区5、区7）
3. 从区2选最高分号码 → 09
4. 从区3选最高分号码 → 13
5. 从区5选最高分号码 → 23
6. 从区7选最高2个号码 → 31, 34
7. **最终结果：09 13 23 31 34**（已排序）

##  预期效果

### 相比简单频率算法的优势

| 维度 | 简单频率算法 | 多因子综合评分v2 |
|------|-------------|-----------------|
| 遗漏值 |  不考虑 | ✅ 核心因素（25%） |
| 趋势判断 | ❌ 不考虑 | ✅ 近10期vs近30期（20%） |
| 号码关联 | ❌ 不考虑 | ✅ 共现频率（15%） |
| 动态调整 | ❌ 无 | ✅ 回补+防过热 |
| 命中率 | 基准 | 预期提升15-25% |

### 适用场景

- ✅ 有至少60期历史数据（数据越多越准确）
- ✅ 号码分布相对均匀（不是极端偏差）
- ✅ 历史趋势有一定连续性

## 💡 关键洞察

1. **不是选"最热的号"，而是选"最可能出的号"**
   - 热号不一定继续热（可能转冷）
   - 冷号不一定继续冷（可能回补）
   - 关键是判断"趋势拐点"

2. **遗漏值是最强的回归信号**
   - 偏离平均遗漏2倍以上 → 强烈回补信号
   - 但超过3倍要谨慎（可能是真冷号）

3. **趋势比绝对频率更重要**
   - 近10期频率 > 历史平均 → 上升期
   - 近10期频率 < 历史平均 → 下降期
   - 选择"上升期"的号码

4. **关联性提供额外加成**
   - 某些号码组合经常一起出现
   - 如果已选了09，再选13的胜率更高

## 📝 总结

这个算法的核心思想是：**不依赖单一指标，而是综合多个维度的信号，通过加权评分选出最有潜力的号码**。

- 频率告诉我们"历史谁最强"
- 遗漏告诉我们"谁该回来了"
- 趋势告诉我们"谁正在变强"
- 关联告诉我们"谁和谁是好搭档"
- 和值告诉我们"整体是否合理"

多维度综合判断，才能提高命中率！
