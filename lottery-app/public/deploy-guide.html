🌐 Netlify 部署指南

将彩票分析器发布到互联网，让所有人都可以访问

🚀 快速开始（3步完成）

  1. 在项目根目录运行：npm run build
  2. 访问：https://app.netlify.com/drop
  3. 将生成的 dist 文件夹拖拽到网页上即可
✨ 完成！你将获得一个免费的专属链接（如：xxx.netlify.app），支持全球 CDN 加速和 HTTPS

📖 详细部署方法

方法一：拖拽部署（最简单，推荐新手）

  1. 构建项目
    • 打开命令行，进入项目根目录：cd lottery-app
    • 运行构建命令：npm run build
    • 等待构建完成，会生成 dist 文件夹
  2. 上传到 Netlify
    • 访问 Netlify Drop
    • 用文件管理器打开项目的 dist 文件夹
    • 将整个 dist 文件夹拖拽到网页上的虚线框内
  3. 获取访问链接
    • 等待几秒钟，Netlify 会自动部署
    • 部署完成后会显示访问链接（如：https://random-name.netlify.app）
    • 点击链接即可访问你的应用
  4. 自定义域名（可选）
    • 在 Netlify 控制台点击 "Site settings"
    • 找到 "Change site name" 选项
    • 输入你想要的名称（如：lottery-analyzer）
    • 保存后访问链接变为：https://lottery-analyzer.netlify.app
这种方法无需注册账号，适合快速测试和分享。但建议注册账号以便管理多个项目。

方法二：Git 部署（推荐，支持自动更新）

  1. 准备 Git 仓库
    • 将项目推送到 GitHub、GitLab 或 Bitbucket
    • 如果没有 Git 仓库，先初始化：git init
    • 添加所有文件：git add .
    • 提交代码：git commit -m "initial commit"
    • 创建远程仓库并推送
  2. 连接 Netlify
    • 访问 Netlify 并注册/登录
    • 点击 "New site from Git"
    • 选择你的 Git 服务商（GitHub/GitLab/Bitbucket）
    • 授权 Netlify 访问你的仓库
    • 选择要部署的项目
  3. 配置部署选项
    • Branch to deploy: 选择 main 或 master
    • Build command: 输入 npm run build
    • Publish directory: 输入 dist
    • 点击 "Deploy site"
  4. 享受自动部署
    • 每次推送到主分支，Netlify 会自动重新构建和部署
    • 可以在 Netlify 控制台查看部署历史和日志
    • 支持回滚到之前的版本
Git 部署的优势：代码更新后自动部署，无需手动操作，适合长期维护的项目。

⚙️ 高级配置

自定义域名

  1. 在 Netlify 控制台进入 "Domain settings"
  2. 点击 "Add custom domain"
  3. 输入你的域名（如：lottery.example.com）
  4. 按照提示配置 DNS 记录（通常是 CNAME 记录）
  5. 等待 DNS 生效（通常几分钟到几小时）
  6. Netlify 会自动配置 HTTPS 证书

环境变量

如果你的应用需要 API 密钥等敏感信息：

  1. 在 Netlify 控制台进入 "Site settings" → "Environment variables"
  2. 点击 "Add a variable"
  3. 添加变量名和值
  4. 重新部署使配置生效

重定向规则

项目已包含 netlify.toml 配置文件，确保 SPA 路由正常工作。

❓ 常见问题

Q: 为什么我的页面刷新后出现 404？

A: 这是 SPA（单页应用）的正常现象。项目已配置 netlify.toml 文件，确保所有路由都指向 index.html。如果仍有问题，检查该文件是否存在。

Q: 如何更新已部署的网站？

A:

  • 拖拽部署：重新拖拽新的 dist 文件夹覆盖
  • Git 部署：推送新代码到主分支，自动触发部署

Q: 数据会保存在哪里？

A: 当前版本的数据保存在每个用户的浏览器本地（localStorage）。不同用户之间不共享数据。如果需要云端同步，需要额外开发后端服务。

Q: 可以绑定自己的域名吗？

A: 可以！在 Domain settings 中添加自定义域名，并按照指引配置 DNS 记录即可。

Q: 部署失败怎么办？

A:

  • 检查构建命令是否正确（应该是 npm run build）
  • 确认发布目录是 dist
  • 查看部署日志，查找错误信息
  • 确保项目根目录有 package.json 文件
