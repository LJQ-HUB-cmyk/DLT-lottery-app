## 📝 数据格式要求

每行一条记录，格式为：
```
前区5个号码(空格分隔) 后区2个号码(空格分隔)
```

示例：
```
03 09 17 26 35 02 07
01 06 08 27 32 03 04
```

**注意事项**：
- 号码必须是2位数（不足补0）
- 前区范围：01-35
- 后区范围：01-12
- 按时间顺序排列（旧的在前，新的在后）
