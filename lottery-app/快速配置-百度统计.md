# 🚀 3步搞定数据统计（百度统计 - 国内推荐）

## 第 1 步：获取站点 ID（2分钟）

1. 访问 https://tongji.baidu.com
2. 用百度账号登录
3. 点击"新增网站"，填写：
   - 网站域名：您的部署域名
   - 网站名称：发财大计
4. 复制得到的**纯数字站点 ID**

---

## 第 2 步：配置文件（1分钟）

在 `lottery-app` 目录创建 `.env` 文件：

```env
VITE_BAIDU_TONGJI_ID=您的数字ID
```

**示例：**
```env
VITE_BAIDU_TONGJI_ID=12345678901234567890
```

---

## 第 3 步：编译部署（1分钟）

```bash
cd d:\0.Code\0.发财大计\lottery-app
npm run build
```

然后部署到 GitHub Pages / Vercel
