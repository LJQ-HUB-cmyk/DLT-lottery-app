# 授权功能使用说明

## 功能概述

已为"发财大计"应用添加了授权验证功能，无论是通过APK安装还是访问网页版（https://wangzhengwei-gua.github.io/lottery-app/），用户都需要输入正确的授权码才能使用应用。

## 当前授权码

**默认授权码：`888888`**

## 如何修改授权码

### 本地开发环境

1. 打开文件：`e:\lottery-app\lottery-app\.env.local`
2. 修改 `VITE_AUTH_CODE` 的值：
   ```
   VITE_AUTH_CODE=your_new_code
   ```
3. 保存文件后重新运行 `npm run dev` 即可

### GitHub Pages 部署

1. 进入 GitHub 仓库页面
2. 点击 **Settings** → **Secrets and variables** → **Actions**
3. 点击 **New repository secret**
4. 名称填写：`VITE_AUTH_CODE`
5. 值填写你的授权码
6. 点击 **Add secret**
7. 提交代码后，GitHub Actions 会自动使用这个授权码构建

⚠️ **重要**：`.env.local` 文件已在 `.gitignore` 中，不会被提交到 Git，保证授权码安全！

## 功能特性

### 1. 授权验证页面
- 首次访问时显示授权输入界面
- 精美的渐变背景和卡片设计
- 输入错误时有抖动动画提示
- 支持密码模式输入（隐藏授权码）

### 2. 授权状态持久化
- 授权成功后，状态保存在浏览器本地存储中
- 下次访问无需再次输入授权码
- 清除浏览器缓存后会要求重新授权

### 3. 退出功能
- 主应用右上角有"退出"按钮
- 点击后可清除授权状态
- 下次访问需要重新输入授权码

### 4. 跨平台支持
- ✅ Android APK 版本
- ✅ 网页版（GitHub Pages）
- ✅ iOS 版本（如果后续开发）

## 工作流程

```
用户访问应用
    ↓
检查本地是否有授权记录
    ↓
有授权 → 直接进入主应用
    ↓
无授权 → 显示授权页面
    ↓
输入授权码
    ↓
验证通过 → 保存授权状态 → 进入主应用
验证失败 → 显示错误提示 → 重新输入
```

## 安全说明

✅ **当前方案已优化**：
- 授权码存储在环境变量中，不在代码中硬编码
- `.env.local` 文件已被 `.gitignore` 忽略，不会提交到 Git
- GitHub Pages 使用 GitHub Secrets 存储授权码，构建时注入
- 即使查看源代码，也只能看到编译后的值，无法直接获取原始授权码

⚠️ **注意**：
- 前端验证本质上仍可以被懂技术的用户通过浏览器开发者工具查看
- 适合简单的访问控制，不适合高安全性场景
- 如果需要更强的安全性，建议改用后端验证

## 增强安全性建议（可选）
