# 自动获取开奖数据功能说明

## 功能概述

本项目已实现大乐透开奖数据的自动获取功能，通过 GitHub Actions 定时从中国体彩网或网易彩票抓取最新开奖数据，并自动更新到代码仓库中。

## 工作原理

### 1. 爬虫脚本
- 位置：`lottery-app/scripts/fetch-lottery-data.js`
- 功能：从多个 API 源获取最新一期大乐透开奖数据
- 特性：
  - 支持双 API 方案自动切换
    - 方案 1：api100.duapp.com (GET 请求)
    - 方案 2：api.xinti.com (POST 请求，带签名)
  - 自动去重，避免重复添加
  - 自动维护最多 100 条历史记录
  - 支持容错和重试
  - API 不可用时提示手动维护

### 2. GitHub Actions 定时任务
- 位置：`.github/workflows/auto-fetch-lottery.yml`
- 运行时间：每周一、三、六晚上 23:00（北京时间）
- 大乐透开奖后自动执行
- 自动提交更新的数据到仓库

### 3. 数据加载
- 位置：`lottery-app/src/data/lottery-history.txt`
- 应用启动时自动加载此文件
- 优先级：外部数据文件 > LocalStorage > 默认数据

## 使用方法

### 自动模式（推荐）

无需任何操作，GitHub Actions 会在开奖后自动获取数据并更新。

### 手动触发

如果需要立即获取最新数据：

1. 访问 GitHub 仓库页面
2. 点击 "Actions" 标签
3. 选择 "Auto Fetch Lottery Data" 工作流
4. 点击 "Run workflow" 按钮
5. 等待执行完成（约 1-2 分钟）

### 本地测试

在本地运行爬虫脚本：

```bash
cd lottery-app
node scripts/fetch-lottery-data.js
```

## 数据格式

数据文件格式（`lottery-history.txt`）：
```
前区1 前区2 前区3 前区4 前区5 后区1 后区2
07 09 23 27 32 02 08
04 08 15 20 31 07 08
```

每行一期，数字用空格分隔，前区 5 个号码，后区 2 个号码。

## 注意事项

1. **网络问题**：如果 API 源都不可用，脚本会失败
2. **频率限制**：GitHub Actions 每月有 2000 分钟免费额度
3. **数据准确性**：数据来自官方 API，但建议以官方公布为准
4. **手动修正**：如果发现数据错误，可以直接编辑 `lottery-history.txt` 文件并提交

## 故障排除

### 问题：GitHub Actions 执行失败

**解决方案**：
1. 检查 Actions 日志，查看具体错误信息
2. 确认网络连接正常
3. 手动触发工作流重试

### 问题：数据没有更新

**解决方案**：
1. 检查是否已是最新一期（脚本会自动去重）
2. 查看 Actions 执行日志
3. 确认开奖时间已过（大乐透每周一、三、六 21:25 开奖）

### 问题：本地运行脚本失败

**解决方案**：
1. 确保 Node.js 版本 >= 18
2. 检查网络连接
3. 查看控制台错误信息

## 自定义配置

### 修改运行时间

编辑 `.github/workflows/auto-fetch-lottery.yml`：

```yaml
schedule:
  - cron: '0 15 * * 1,3,6'  # UTC 时间 15:00 = 北京时间 23:00
```

Cron 表达式格式：`分 时 日 月 星期`

### 添加新的数据源

编辑 `lottery-app/scripts/fetch-lottery-data.js`，在 `DATA_SOURCES` 数组中添加：

```javascript
const DATA_SOURCES = [
  {
    name: '新数据源名称',
    url: 'https://example.com',
    api: 'https://api.example.com/lottery'
  },
  // ...
];
```

然后在 `fetchFromAPI()` 函数中添加相应的数据解析逻辑。

## 技术细节

### API 源

1. **方案 1：api100.duapp.com**
   - 地址：`http://api100.duapp.com/lottery/?type=大乐透`
   - 请求方式：GET
   - 数据格式：JSON (data[1].Title)
   - 特点：简单直接，无需签名

2. **方案 2：api.xinti.com**
   - 地址：`https://api.xinti.com/chart/queryPrizeHistoryByGameCode`
   - 请求方式：POST
   - 数据格式：JSON (Value.GameHistoryInfo)
   - 特点：结构化数据，需要签名和时间戳

### 数据更新流程

```
开奖 → GitHub Actions 触发 → 运行爬虫脚本 → 获取数据 
→ 检查去重 → 更新文件 → Git Commit → Git Push 
→ 应用自动加载新数据
```
