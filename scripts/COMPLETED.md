## 🔧 技术细节

### 数据源分析
**500.com** 的页面标题包含完整信息：
```
大乐透26056期开奖结果 06 07 18 21 30 + 01 05 - 500彩票网
```

通过正则表达式提取：
```python
pattern = r'(\d{2})\s+(\d{2})\s+(\d{2})\s+(\d{2})\s+(\d{2})\s*[+]\s*(\d{2})\s+(\d{2})'
```

### 期号推算逻辑
```python
# 根据当前日期估算期号
year = now.year % 100  # 年份后两位
weeks_passed = day_of_year // 7  # 已过周数
estimated_period = weeks_passed * 3  # 每周3期

# 检查最近20期（带缓冲）
for i in range(20):
    period = f"{year:02d}{estimated_period + 5 - i:03d}"
```

### 工作流程
```
触发 → 估算期号 → 逐个尝试 → 找到最新 → 
解析HTML → 提取号码 → 验证格式 → 
检查重复 → 追加文件 → 提交Git → 完成
```
